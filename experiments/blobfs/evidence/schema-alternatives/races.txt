# Contention: two sessions over each schema, the same interleaving each time.
# s1 opens a transaction and runs the first step; s2 then runs the second step
# in its own transaction; the harness reports whether s2 waited on a row lock;
# s1 commits; the row is read afterwards. UPDATE n is the rows the update
# affected. The file starts in the small directory and the move sends it to
# another depth-six directory.
