==================== a. the shipped projection against the bookmark count ====================
bookmarks as the store composes it under TotalExact, page 1 of 20 in path order: the count twin, then the page. The base computes each row's path by a recursion correlated on the file's directory; the unit is a filter directive outside the derived table.
count as run: SELECT COUNT(*) FROM (SELECT b.unit_id, b.file_id, f.directory_id, b.active,
  (WITH RECURSIVE up (directory_id, path) AS (
      SELECT d.parent_id, CASE WHEN d.parent_id IS NULL THEN '' ELSE '/' || d.name END
      FROM blobfs_directory d
      WHERE d.id = f.directory_id
    UNION ALL
      SELECT d.parent_id, CASE WHEN d.parent_id IS NULL THEN '' ELSE '/' || d.name END || up.path
      FROM up
      JOIN blobfs_directory d ON d.id = up.directory_id
  )
  SELECT up.path FROM up WHERE up.directory_id IS NULL) || '/' || f.name AS path,
  f.name, f.status, f.size, f.content_type, b.created_at, b.updated_at
FROM bookmark b
JOIN blobfs_file f ON f.id = b.file_id) q WHERE q.unit_id = CAST($1 AS uuid)

      FROM blobfs_directory d

    UNION ALL

FROM bookmark b
JOIN blobfs_file f ON f.id = b.file_id) q WHERE q.unit_id = CAST($1 AS uuid) ORDER BY q.path, q.file_id OFFSET $2 ROWS FETCH NEXT $3 ROWS ONLY
